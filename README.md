1. 📱 Staff ID QR – Live Excel Register View

A web-based project designed to make staff identity management more convenient using QR codes.

Key Features:

- Generate QR codes for staff identity details.
- Enter staff name, staff ID, mobile number, and department.
- Download individual QR codes.
- Export staff records to Excel.
- View registered staff records in an Excel-style interface.
- Generate a master QR code to access the application.
